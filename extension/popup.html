Paper Scout backend

Connect to a server running the Paper Scout API.

Leave off to use the backend's AI configuration. When on, your AI URL, model, and key are sent to the selected backend with each investigation. That backend must support custom AI settings.

This URL is reached by the backend. For Docker, localhost refers to the container; use the host address Ruben configures. Local AI servers may use HTTP; use HTTPS for remote servers.

By default, keys last for this browser session. Remembered keys use local extension storage, which is not encrypted. Keys never sync to your browser account.

Saving may ask Chrome for access to the backend host. Use HTTPS for remote backends; HTTP is allowed on localhost and 127.0.0.1. Testing checks API compatibility, not AI credentials.
