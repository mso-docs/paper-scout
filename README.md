# Paper Scout

A browser-based research agent that helps researchers investigate claims without leaving the paper they’re reading.

Our project for AI Tinkerers Atlanta 2026.

## The MVP

**Highlight text → “Scout this claim” → agent researches → evidence appears in a browser sidebar.**

1. Highlight a claim or passage in the paper you’re reading.
2. Select **“Scout this claim”** to start an investigation.
3. Paper Scout uses the surrounding page as context to autonomously search for related research and identify supporting and conflicting evidence.
4. Review a concise evidence summary with sources in a browser sidebar.

## Why Paper Scout?

Paper Scout lives where research happens—the browser. Researchers can investigate a claim in context, with the paper and evidence side by side, without copying passages into a separate AI application.

## MVP scope

- Claim selection from highlighted text.
- Context-aware research using the surrounding page.
- Autonomous search for related research.
- Supporting and conflicting evidence with sources.
- Concise results in a browser sidebar.
